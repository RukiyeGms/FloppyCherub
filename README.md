# Floppy Cherub

**Floppy Cherub** is a cute, pastel pixel-art game inspired by Flappy Bird, developed in Unity.

This project was created as a small practice game to learn and experiment with **GitHub collaboration, branches, pull requests, and version control** while working as a team.
